Detailed Description

Represents a 3x3 truth table:

. 

                         Input of True
                         Result is ...

                          False      Mixed        True
                        +==========+==========+==========+
                 False  | ALWAYS_F │ AND      │ IDENTITY |
Input of False          |──────────┼──────────┼──────────|
Result is ...    Mixed  | INV_AND  │ CONTRIB  │ OR       |
                        |──────────┼──────────┼──────────|
                 True   | INVERSE  │ INV_OR   │ ALWAYS_T |
                        +==========+==========+==========+

The NONE influence is used to indicate that an input is not related to, and thus does not influence, the result of a condition.
