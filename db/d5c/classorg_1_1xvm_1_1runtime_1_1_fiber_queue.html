◆ isAnyNonConcurrentWaiting()

boolean org.xvm.runtime.FiberQueue.isAnyNonConcurrentWaiting ( Fiber fiberCandidate)
private

Check if there is any "waiting" frame that is not concurrent safe with regard to the specified fiber.

Note1: this method should be called only if the service is Concurrent (i.e. frame-dependent) Note2: if this method returns true, it also sets the "blocker" on the evaluating fiber

Parameters
fiberCandidatethe fiber that the service is evaluating for execution (either Initial or Waiting)
Returns
true iff there are any non-concurrent waiting frames
