Detailed Description

A representation of the file structure that contains one or more Ecstasy (XVM) modules.

The FileStructure is generally used as a container of one module, which may have dependencies on other modules, some of which may be wholly embedded into the file structure. In other words, the FileStructure is the "module container".

ModuleConstant org.xvm.asm.FileStructure.m_idModule
private

The id of the main module that the FileStructure represents.

There may be additional modules in the FileStructure, but generally, they only represent imports (included embedded modules) of the main module.

Note: for persistent file structures the main module id is never versioned (its version is null).
