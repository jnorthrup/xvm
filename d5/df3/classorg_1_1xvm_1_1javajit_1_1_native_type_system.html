◆ genClass()

byte[] org.xvm.javajit.NativeTypeSystem.genClass ( ModuleLoader moduleLoader,
String name )

Create a Java ClassFile for the specified class name.

The name follows a very exact convention for how it is constructed, and that convention is well understood by the TypeSystem (because that name was created by the TypeSystem).

Parameters
moduleLoaderthe ModuleLoader that contains the structure information for the containing module and all its classes
namethe suffix of the Java class name to create (sans the module prefix)
Returns
the bytes of the ClassFile for the specified class name
