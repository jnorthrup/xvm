◆ f_fStrict

final boolean org.xvm.runtime.template.Proxy.ProxyHandle.f_fStrict
protected

If true, the proxy can only be seen/used as the "proxy type".

Otherwise, if the caller [container] can cast the underlying target to a type that is a part of its type system, the proxy handle will allow it.
