◆ narrowType()

Register org.xvm.asm.Register.ShadowRegister.narrowType ( TypeConstant typeNarrowed)

Create a register that is collocated with this register, but narrows its type.

To be technically correct, there are scenarios when typeNarrowed is actually wider than the original type. Imagine a following Ecstasy code: 


  Element el = ...;
  Consumer<Element> consumer1 = new Consumer(Element>();
  if (Element.is(Type<Int>))
      {
      Consumer<Element> consumer2 = new Consumer(Element);
  }

In the enclosed "if" context it's known that the Element is an Int, which makes consumer2 not assignable to (not narrower than) consumer1, but in effect wider.

Parameters
typeNarrowedthe new register type
Returns
a shadow of the original register reflecting the new type
