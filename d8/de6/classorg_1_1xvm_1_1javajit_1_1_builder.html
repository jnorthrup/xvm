final String org.xvm.javajit.Builder.XVM_PRIMITIVE_COMPARE = "$compare"
static

The name of the internal compare method expected to be present on XVM primitive types.

The signature should be: 

    public int $compare(primitive p1, primitive p2 ...)

Where the method returns an int and takes as parameters two sets of the primitive types that make up the XVM primitive type. For example, an Int128 type is made up of two Java long values, so its compare signature would be: 

    public int $compare(long low1, long high1, long low2, long high2)
