Any exception thrown by the called function will be reported as an "UnhandledExceptionNotification" (see Service.x).

TypeSupplier org.xvm.runtime.ServiceContext.resolveFormalReturnTypes ( FunctionHandle hFunction,
ObjectHandle[] ahArg )
private

Helper method to resolve the formal type parameters in the function's return type.

This method is only called if the value returned by the service is not immutable and needs to be proxied. In that case the actual return value type could be used to resolve generic return types (see ClassTemplate.createProxyHandle), but formal type parameters can only be resolved using the type parameters types that are passed in by the caller.

◆ m_lLockScheduling

volatile long org.xvm.runtime.ServiceContext.m_lLockScheduling
package

The context scheduling "lock", atomic operations are performed via SCHEDULING_LOCK_HANDLE.

This lock must be acquired in order to schedule context processing and is not released until the context is no longer scheduled.

The lock is implemented as a volatile counter, the thread which transitions from 0 to 1 becomes the lock holder will release the lock by setting back via a getAndSet(0), which, if it yields a prior value of something other than 1, indicates the lock contention.
