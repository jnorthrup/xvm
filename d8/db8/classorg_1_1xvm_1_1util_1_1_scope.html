Detailed Description

A fluent Java utility that emulates Kotlin's scope functions: let, also, apply, run, and with.

Based on the semantics described in the Kotlin documentation.

Design Goals

  • Preserve Kotlin semantics: let/run return block result, also/apply return the original object
  • Enable fluent chaining
  • Support nullable values (Optional-style)
  • Remain idiomatic, pure Java (no reflection, no bytecode tricks)

Limitations (Java vs Kotlin)

  • Lambdas cannot have implicit this or it
  • No smart casts
  • Null-safety must be explicit

Quick Example



Person person = Scope.on(new Person())

    .apply(p -> {

        p.setName("Alice");

        p.setAge(30);

    })

    .also(p -> System.out.println("Created: " + p))

    .get();



String label = Scope.on(person)

    .let(p -> p.getName() + " (" + p.getAge() + ")");

Scope< T > org.xvm.util.Scope< T >.also ( Consumer<? super T > block)

Scope Function: Executes a side effect block and returns the Scope for chaining.

Equivalent to Kotlin's obj.also { println(it) }. Use for side effects like logging, validation, or debugging without breaking the chain.

Example



Person person = Scope.on(new Person())

    .apply(p -> p.setName("Alice"))

    .also(p -> System.out.println("Created: " + p))

    .also(p -> log.debug("Person id: {}", p.getId()))

    .get();



// Validate and continue

String result = Scope.on(input)

    .also(s -> Objects.requireNonNull(s, "input required"))

    .also(s -> { if (s.isEmpty()) throw new IllegalArgumentException(); })

    .let(String::trim);

Scope< T > org.xvm.util.Scope< T >.apply ( Consumer<? super T > block)

Scope Function: Executes a configuration block and returns the Scope for chaining.

Equivalent to Kotlin's Obj().apply { x = 1; y = 2 }. Use for configuring or initializing an object. Semantically identical to also, but communicates intent: apply is for configuration, also is for side effects.

Example



StringBuilder sb = Scope.on(new StringBuilder())

    .apply(b -> b.append("Hello"))

    .apply(b -> b.append(" "))

    .apply(b -> b.append("World"))

    .get();

// sb.toString() = "Hello World"



HttpRequest request = Scope.on(new HttpRequest())

Factory Method: Entry point for scope chaining.

Wraps a value in a Scope to enable fluent method chaining with scope functions. Equivalent to Kotlin's obj.run { ... } or obj.let { ... }.
