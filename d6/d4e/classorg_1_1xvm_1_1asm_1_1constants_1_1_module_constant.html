Detailed Description

Represent a Module constant.

A Module constant is composed of a qualified module name, which itself is composed of a domain name and an unqualified (simple) module name. For example, the domain name "xtclang.org" can be combined with the simple module name "ecstasy" to create a qualified module name of "ecstasy.xtclang.org".
