◆ getStderrPath()

Property< @NotNull String > org.xtclang.plugin.internal.DefaultXtcLauncherTaskExtension.getStderrPath ( )

File path pattern for stderr redirection.

Supports timestamp placeholder TIMESTAMP% which expands to yyyyMMddHHmmss format at execution time.

Can be set in multiple ways: 

// Direct string (supports TIMESTAMP% placeholder)
stderrPath.set("build/logs/errors-%TIMESTAMP%.log")

// Provider from layout (lazy, configuration cache compatible)
stderrPath.set(layout.buildDirectory.file("logs/errors.log").map { it.asFile.absolutePath })

// Convenience method with File
stderrPath(project.file("my-errors.log"))

// Convenience method with Provider<RegularFile>
stderrPath(layout.buildDirectory.file("logs/errors.log"))

If not set, stderr will be inherited from the parent process (normal fork) or redirected to a default timestamped log file (detached mode).

Returns
the stderr file path pattern property
