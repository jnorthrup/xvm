Detailed Description

Weak reference for the function that is to be called at some point in the future on the context of the specified frame if the corresponding service is still running.

The idea behind the WeakCallback is that it can retrieve all necessary information to create a ServiceContext.CallLaterRequest using a unique id, but does not itself hold that data, therefore not preventing the underlying service from being stopped and GC'd.
