Detailed Description

A ModuleLoader is responsible for loading exactly one module with a specified set of attributes such as the module version, the absence/presence of other modules, and a set of defined (or explicitly undefined) names.

Construct a ModuleLoader.

Since modules can be dependent on other modules within the same TypeSystem, the parent ClassLoader is always the TypeSystemLoader responsible for introducing (bringing into existence) the module.

Parameters
pkgthe '.'-delimited Java package name assigned to this loader and corresponding to the module, which in theory this loader will "own" responsibility for loading all classes under that package, and nothing outside of that package
parentthe TypeSystemLoader within which the module is being loaded
modulethe ModuleStructure that this loader is responsible for loading
