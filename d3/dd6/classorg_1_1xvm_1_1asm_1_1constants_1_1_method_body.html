private

The resolved method signature.

The MethodBody cannot resolve a signature, because the necessary information is external to the MethodInfo and MethodBody, yet it is required to have the resolved signature so that collisions can be detected and the method chains will be correctly assembled.

◆ m_target

final Object org.xvm.asm.constants.MethodBody.m_target
private

The constant denoting additional information (if required) for the MethodBody implementation:

  • For Implementation Capped, this specifies a resolved nid for the narrowing method that the cap redirects execution to via a virtual method call;
  • For Implementation Delegating, this specifies the property which contains the reference to delegate to.
  • For Implementation Field, this specifies the property that the method body corresponds to. For example, this is used to represent the field access for a get() method on a property.
