Detailed Description

A module compiler for Ecstasy code.

The compiler is a multi-step state machine. This design is the result of the compiler for one module needing to be able to be coordinated with compilers for other modules that are co-dependent, i.e. that have dependencies on each other that need to be jointly resolved.
