◆ m_hReferent

ObjectHandle org.xvm.runtime.template.reflect.xRef.RefHandle.m_hReferent
protected

For a lack of a better name, this field holds either.

  • the referent itself (InjectRefHandle, m_iVar = REF_REFERENT),
  • a delegation to another RefHandle (m_iVar = REF_REF),
  • a property container (m_iVar = REF_PROPERTY),
  • an array holding the referent (IndexRefHandle, m_iVar = REF_ARRAY),
  • a delegation to a frame variable (m_frame != null, m_iVar >= 0), or
  • null, for m_iVar = REF_REFERENT, in which case the field REFERENT holds the value

What is quite important is that this field must not change while set - this will ensure the correct behavior of a cloneAs operation.
