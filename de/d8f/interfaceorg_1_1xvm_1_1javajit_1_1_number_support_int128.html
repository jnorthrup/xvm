Build the optimized binary operation that will add two XVM primitive types that are each represented by two Java long primitive values.

(T + T -> T).

Neither the target nor argument should have been loaded to the stack.

The result will be represented by two Java long primitive values on the stack. The top of the stack will be the high long value and below that will be the low long value.

Parameters
codethe code builder to add the op codes to
bctxthe current build context
slotL1the slot containing the low long for the first value
slotH1the slot containing the high long for the first value
slotL2the slot containing the low long for the second value
slotH2the slot containing the high long for the second value

Load the shift argument for an Int128 or UInt128 shift left operation.

To remain consistent with other Java shift operations, the shift argument is masked with the maximum number of bits that can be shifted (in this case seven bits, 0x7F).
