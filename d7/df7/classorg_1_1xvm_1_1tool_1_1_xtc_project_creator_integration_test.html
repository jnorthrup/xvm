Detailed Description

Integration tests for XtcProjectCreator that verify generated projects are valid Gradle projects that can be configured successfully.

These tests create actual projects and run ./gradlew tasks to verify the build files are syntactically correct and the project structure is valid.

DISABLED BY DEFAULT: These tests spawn separate Gradle processes for each generated project, which downloads dependencies, the Gradle wrapper, and configures the project from scratch. With an empty cache, this adds several minutes to the build.

Requirements:

  • The XTC plugin must be available in mavenLocal() - run ./gradlew publishLocal first
  • Network access for Gradle wrapper download (first run only)

Enable these tests by setting environment variable: RUN_INTEGRATION_TESTS=true
