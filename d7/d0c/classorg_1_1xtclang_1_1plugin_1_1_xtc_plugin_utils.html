String org.xtclang.plugin.XtcPluginUtils.expandTimestampPlaceholder ( final String pathPattern)
static

Expands TIMESTAMP% placeholder in a file path pattern to yyyyMMddHHmmss format.

This format matches the timestamp used throughout the XTC plugin for log files.

Parameters
pathPatternThe path pattern that may contain TIMESTAMP% (must not be null)
Returns
The path with timestamp placeholder expanded, or the original path if no placeholder found
