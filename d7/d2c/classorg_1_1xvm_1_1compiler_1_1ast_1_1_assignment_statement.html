Detailed Description

An assignment statement specifies an l-value, an assignment operator, and an r-value.

Additionally, this can represent the assignment portion of a "conditional declaration".

◆ isRValue()

boolean org.xvm.compiler.ast.AssignmentStatement.isRValue ( Expression exprChild)
protected

Test if the specified child is used as an R-Value, which is something that yields a value.

In most cases, an expression is used as an R-Value (i.e. it has a value), but an expression can be used as a left side of an assignment, for example, which makes it an L-Value. In a few cases, an expression can be used as both an R-Value and an L-Value, such as with the pre-/post-increment/-decrement operators.

Parameters
exprChildan expression that is a child of this node
Returns
true iff the child is used as an R-Value

VariableDeclarationStatement[] org.xvm.compiler.ast.AssignmentStatement.takeDeclarations ( )

For each explicit variable declaration that provides an L-Value for this AssignmentStatement, separate the VariableDeclarationStatement from this AssignmentStatement such that the AssignmentStatement will no longer cause the variable to be declared, and instead will just use the variable declared by the statement.

(It becomes the responsibility of the caller of this method to ensure that the VariableDeclarationStatement is processed before this AssignmentStatement.)

all of the VariableDeclarationStatements that are used as L-Values by this statement
