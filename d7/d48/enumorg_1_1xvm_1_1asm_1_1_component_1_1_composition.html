◆ Annotation

org.xvm.asm.Component.Composition.Annotation

Represents an annotation.

The constant is a TypeConstant. (It could be a ClassConstant, but TypeConstant was selected to keep it compatible with the other compositions.) An annotation has optional annotation parameters, each of which is also a constant from the ConstantPool.

org.xvm.asm.Component.Composition.Delegates

Represents interface inheritance plus default delegation of interface functionality.

The constant is a TypeConstant. A "delegates" composition must specify a property that provides the reference to which it delegates; this is represented by a PropertyConstant.
