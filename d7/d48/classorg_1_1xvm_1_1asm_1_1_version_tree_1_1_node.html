Detailed Description

Represents a node within the version tree.

All nodes are used for building the hierarchical organization of tree, but only a node that has a value is considered to be "present" in the tree.

Node org.xvm.asm.VersionTree< V >.Node< V >.findHighestNode ( )
package

Find a node (from this point down in the tree) that represents the "latest version" by a non-strictly-ordered measure:

  • Versions parts are evaluated left to right;
  • A higher version part number is assumed to be later;
  • A GA version is preferred over a non-GA version, even if the non-GA version is a provably later version.
Returns
the node that represents the highest version, using the rules defined by this method, or null if no node is present from this point down in the tree
