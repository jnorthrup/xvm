Detailed Description

The AssemblerContext is used to notify the assembler of changes in the current set of conditions during the assembly process.

For example, when a compiler is emitting XVM structures, it will modify the assembler context to notify the assembler each time it enters or leaves a conditional scope of code.

The challenge is to factor out redundancy

◆ getModificationIndicator()

long org.xvm.asm.AssemblerContext.getModificationIndicator ( )

Obtain a modification indicator for the data structure.

The modification indicator provides a very fast way to determine if a change to the contents of the data structure has occurred; if the modification indicator has not changed, then the contents of the structure are identical to what they were. (Note that the opposite is not necessarily true: If the modification indicator has changed, it is possible that the contents are identical to what they were, in which case a detailed evaluation of the contents would be necessary to prove equality or inequality.)

Returns
an opaque value that can be compared to another return value from this same method
