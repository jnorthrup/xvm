Detailed Description

Base class for forked (out-of-process) execution strategies.

Handles common logic for building ProcessBuilder and executing forked JVM processes.

List< Thread > org.xtclang.plugin.launchers.ForkedStrategy.copyProcessStreams ( final Process process,
final StreamPlan streamPlan )
protected

Copies process stdout/stderr to System.out/err in background threads.

This is necessary when Gradle has redirected file descriptors and inheritIO() doesn't work. Uses byte-buffer based copying (like Gradle's implementation) for better performance and to capture all output including partial lines.

Parameters
processthe process whose streams to copy
Returns
list of threads copying the streams
