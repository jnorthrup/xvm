Cursor Blackboard — Cursor Tree Architecture

Trikeshed: Join/Series algebra → ColumnMeta↻ lazy projections → Cursor

Lazy Projection Contract

  • • `ColumnMeta↻` = () → ColumnMeta — lazy metadata supplier
  • • Each RowVec carries independent per-element ColumnMeta↻ generators
  • • Metadata never pre-materialized — evaluated on demand via b(i).b()
  • • Row 0 is the idempotent meta exemplar: its ColumnMeta↻ define schema

RowVec / Cursor Expansion Chain

  • • `ColumnMeta↻` := () → ColumnMeta
  • • RowVec := Series2<Any?, `ColumnMeta↻`>
  • • Cursor := Series<RowVec>
  • • Full: Series<Series<Join<Any?, () → Join<CharSequence, Join<TypeMemento, ColumnMeta?>>>>>

ColK Facet Algebra

  • • ColK.ByIndex(col: Int) → column by position
  • • ColK.ByName(name: CharSequence) → column by name
  • • ColK.Meta → Series<ColumnMeta> (projected per column)
  • • ColK.Width → Int (row width singleton)
