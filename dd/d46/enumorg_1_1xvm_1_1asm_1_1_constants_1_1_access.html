Detailed Description

The Access enumeration refers to the level of accessibility to a class that a reference will have:

  • STRUCT - direct access to the underlying data structure (but only to the data structure);
  • PUBLIC - access to the public members of the object's class;
  • PROTECTED - access to the protected members of the object's class;
  • PRIVATE - access to the private members of the object's class;
