Detailed Description

The runtime context of a logical thread of execution.

Enables multiple returns, tuple return functionality, etc.

Ideally, this struct will fit inside two cache lines, with the hot fields in the first line.

◆ realloc()

void org.xvm.javajit.Ctx.realloc ( long oldSize,
long newSize )

Used when a copy is being made, such that some old memory is still (temporarily) required to perform the copy, while the new memory (which could be larger or smaller) needs to be allocated.

Like alloc(long), this call may return immediately, wait indefinitely (i.e. park this virtual thread and schedule a different fiber to run), or even kill the current container. It is expected that the algorithm behind this differs slightly from alloc(long), in that this method will permit the memory limits to be exceeded on a temporary basis as long as the result does not imperil the health of the xvm.

Parameters
oldSizethe memory still being held onto temporarily that will be freed in a moment
newSizethe new memory being requested (the full amount, not just the delta amount)
