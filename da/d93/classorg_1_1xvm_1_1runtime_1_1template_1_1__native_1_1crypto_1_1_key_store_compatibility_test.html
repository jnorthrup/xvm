Detailed Description

Drop-in compatibility tests that verify the pure Java implementation produces keystores and entries that are interchangeable with those created by the native keytool/openssl commands.

Tests annotated with @EnabledIf("isKeytoolAvailable") run only when keytool is on the PATH. Tests annotated with @EnabledIf("isOpensslAvailable") run only when openssl is on the PATH.
