Detailed Description

Represents the context that a linker has when linking a module into a runtime Container.

The context provides answers from the point of view of the module being linked, i.e. from some "this" module's point of view – including information (like version) about this module, what other modules (and what versions of those modules) are available in the container, and what named link-time options are specified.
