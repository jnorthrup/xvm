Detailed Description

Sanity checks for the versions written into a generated gradle/libs.versions.toml.

Regression coverage for the auto-updated IntelliJ/VS Code plugin baking its own publication build-id (base + UTC timestamp, e.g. 0.4.4-SNAPSHOT.20260526090539) into the catalog, which is not a resolvable Maven/Gradle coordinate. The catalog must only ever pin a real XTC version: MAJOR.MINOR.PATCH optionally with -SNAPSHOT, -alpha, or -beta – and nothing else. Both the snapshot dependency and a "real" (released) dependency must work.
