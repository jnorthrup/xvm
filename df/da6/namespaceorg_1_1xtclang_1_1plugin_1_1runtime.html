package

Build-scoped cache key for an isolated direct runtime.

The fingerprint intentionally tracks the plugin code source as well as the resolved launcher runtime entries. That prevents a reused direct-runtime entry from surviving a plugin rebuild within the same build session, and it avoids assuming that a stable path always means stable contents.
