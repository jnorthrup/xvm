◆ modules

final ArrayList<ModuleStructure> org.xvm.javajit.Linker.modules = new ArrayList<>()
private

These are the modules that have been added to the Linker.

They are potentially unrefined, which means that the linking step would need to ensure that each of these is refined down to a single version with all dependencies resolved (particularly making decisions on optional dependencies) and with all conditionals resolved (version-related, dependency-related, and named conditions).
