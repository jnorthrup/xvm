◆ findClosestVersion()

Version org.xvm.asm.VersionTree< V >.findClosestVersion ( Version ver)

Find the closest version (that is present in the tree) to the specified version, and return it.

The "closest version" must be substitutable for the specified version, which means it needs to be the exact same version as specified, or it needs to unambiguously precede it.

Consider the following tree: 

VersionTree
|- 1:                v1
|- 2:                v2
|  |- 0:             v2.0
|  |- 1:             v2.1
|  |  |- 0:          v2.1.0
|  |     |- 0:       v2.1.0.0
|  |     |- 1:       v2.1.0.1
|  |        |- 0:    v2.1.0.1.0
|  |           |- 0: v2.1.0.1.0.0
|  |- 2:             v2.2
|- 4:                v4

Examples:

  • findClosestVersion(1) -> v1
  • findClosestVersion(2) -> v2.0
  • findClosestVersion(3) -> v2
  • findClosestVersion(4) -> v4
  • findClosestVersion(5) -> v4
  • findClosestVersion(1.5) -> v1
  • findClosestVersion(2.1beta) -> v2.0
  • findClosestVersion(2.1) -> v2.1.0.0
  • findClosestVersion(2.1.0) -> v2.1.0.0
  • findClosestVersion(2.1.1) -> v2.1.0
  • findClosestVersion(2.1.0.1) -> v2.1.0.1.0.0
  • findClosestVersion(2.1.0.1.1) -> v2.1.0.1.0
  • findClosestVersion(2.1.0.2) -> v2.1.0.1
  • findClosestVersion(2.5.1.3) -> v2.2
Parameters
verthe version to search for
Returns
the closest version that is present in the tree
