Configures compile tasks to depend on their associated resource processing tasks.

For each compile task, this method looks up the source sets associated with that task and adds dependencies on both XTC and Java resource processing tasks for those source sets.

◆ createDefaultTestTask()

void org.xtclang.plugin.XtcProjectDelegate.createDefaultTestTask ( final Project project)
private

Create the XTC test task.

This task runs xunit tests for XTC modules. The test task depends on compile tasks and is wired into the Gradle check lifecycle.

The task can be skipped by setting the project property -PskipXtcTests.

Lifecycle Design Note: We intentionally wire testXtc to the check task rather than making the Java plugin's test task depend on it. This provides granularity for projects that have both Java and XTC tests:

  • ./gradlew testXtc - runs only XTC tests
  • ./gradlew test - runs only Java tests
  • ./gradlew check or ./gradlew build - runs both
