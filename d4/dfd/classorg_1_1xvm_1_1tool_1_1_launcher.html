  • xcc ("ecstasy") routes to Compiler
  • xec ("exec") routes to Runner

Registry of available commands.

Each entry maps a command name to a handler that parses the args and launches the appropriate tool.

Note: We use string literals here instead of calling subclass static methods (e.g., Compiler.getCommandName()) to avoid class loading deadlock - referencing subclass static methods from superclass static initialization can cause deadlock.
