◆ registerStructures()

void org.xvm.compiler.ast.TypedefStatement.registerStructures ( StageMgr mgr,
ErrorListener errs )
protected

First logical compiler pass.

  • At this point, names are NOT resolvable; we're really just organizing the tree and checking for errors that are obvious from "this point down" (no lateral evaluation of structures, because we can't count on them even existing yet.)

  • The general idea is that this method recurses through the structure, allowing each node to introduce itself as the parent of each node under it, and that the nodes which will be structures in the resulting FileStructure will register themselves.

  • Type parameters for the types must also be registered, because they are also types, and they will be required to already be present when the second pass begins.
Parameters
mgrthe Stage Manager that is conducting the processing
errsthe error list to log any errors etc. to
