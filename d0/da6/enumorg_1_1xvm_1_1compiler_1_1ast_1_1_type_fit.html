Detailed Description

Represents the ability of an expression to yield a requested type:

  • NoFit - the expression can not yield the requested type;
  • ConvPackUnpack - the expression can yield the requested type via a combination of @Auto type conversion, tuple packing, and tuple unpacking;
  • ConvPack - the expression can yield the requested type via a combination of @Auto type conversion and tuple packing;
  • ConvUnpack - the expression can yield the requested type via a combination of @Auto type conversion and tuple unpacking;
  • Conv - the expression can yield the requested type via @Auto type conversion;
  • PackUnpack - the expression can yield the requested type via a combination of tuple packing and tuple unpacking;
  • Pack - the expression can yield the requested type via tuple packing;
  • Unpack - the expression can yield the requested type via tuple unpacking;
  • Fit - the expression can yield the requested type.
