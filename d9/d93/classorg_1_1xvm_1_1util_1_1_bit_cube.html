Detailed Description

BitCube is a multi-dimensional set of bits.

For every multi-dimensional point (N0, N1, ...) the corresponding bit's id is calculated as: 


   N0 + D0*(N1 + D1*(N2 + ...))
  where Di is a size of dimension i.
